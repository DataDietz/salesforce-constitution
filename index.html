Three workflows to remember

Enough coverage without turning the router into a maze.

Existing feature iteration

Define delta→1 executor→Regression→Ship

UI → Cursor. SF code/config → Vibes. Data/report/bulk → Gemini. Git/CI → Cursor.

Architecture, permissions, data ownership, or integration change? Frontier review can happen first.

Org-wide audit / redesign

Scope rubric→Gemini inventory→Decision packet→Frontier review→Pilot

Scripts read the huge org. The strong model critiques the CRM/data-pipeline decision, not every raw row.

Net-new product / UI

ChatGPT direction→Cursor prototype→Vibes build→Validate

Use mock data until the interaction feels right. If the deliverable is data, replace Cursor with Gemini.
